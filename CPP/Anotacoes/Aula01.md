# Resumo do Vídeo: *Curso de C++ #01 - Introdução ao Curso* (CFBCursos)

Neste vídeo de abertura do curso, o professor Bruno apresenta os conceitos fundamentais da programação, a importância do C++ e a dinâmica dos componentes do computador na execução de um programa [[02:53](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=173)].

---

## Key Takeaways / Conceitos Apresentados

* **Por que aprender C++?**
* É uma linguagem poderosa que serve de base e sintaxe para diversas outras linguagens de programação [[01:28](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=88)].
* Auxilia fortemente no desenvolvimento do raciocínio lógico [[01:40](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=100)].
* É amplamente ensinada em cursos superiores e de engenharia [[02:14](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=134)].


* **O que é uma Linguagem de Programação?**
* É a forma como os humanos dão instruções para que o computador realize tarefas, desde exibir textos até rodar jogos complexos [[03:24](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=204)].
* C++ é considerada uma linguagem de **médio nível** porque possui facilidades de alto nível (palavras em inglês como `if`, `while`, `return`) [[05:07](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=307), [05:44](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=344)], mas também permite manipular ponteiros e endereços de memória próximos do hardware [[05:14](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=314), [06:29](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=389)].


* **Processo de Compilação:**
* O processador compreende apenas linguagem de baixo nível (linguagem de máquina) [[04:12](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=252)].
* O **compilador** realiza a conversão (tradução) do código-fonte escrito em C++ para a linguagem de máquina [[06:35](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=395), [07:08](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=428)].
* **Compiladores Gratuitos Recomendados:** Code::Blocks e Dev-C++ [[07:58](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=478)].


* **Papel do Hardware e Execução de Softwares:**
* **HD (Disco Rígido):** Dispositivo de armazenamento permanente onde ficam salvos os arquivos e executáveis [[09:28](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=568)].
* **Memória RAM:** Armazena temporariamente o programa quando ele entra em execução [[09:56](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=596)].
* **Processador (CPU) e Sistema Operacional:** O sistema operacional gerencia as permissões e recursos de memória, enquanto o processador executa os cálculos e a lógica de fato [[11:04](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=664), [11:33](http://www.youtube.com/watch?v=nUQKr-ey86Y&t=693)].
