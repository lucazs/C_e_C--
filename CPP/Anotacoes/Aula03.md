# Resumo do Vídeo: *Curso de C++ #03 - Estrutura básica de um programa em C++* (CFBCursos)

Neste vídeo, o professor Bruno apresenta o "esqueleto" ou estrutura fundamental necessária para criar e compilar qualquer programa na linguagem C++ utilizando o compilador **Dev-C++** [[00:19](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=19), [00:42](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=42)].

---

## Key Takeaways / Conceitos Apresentados

* **Biblioteca `<iostream>`:**
* Incluída através do comando `#include <iostream>` [[06:35](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=395)].
* É responsável pelos comandos básicos de **entrada e saída de dados** (Input/Output stream) [[07:00](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=420)].


* **Namespace Standard (`using namespace std;`):**
* Define o espaço de trabalho onde o compilador deve buscar as definições padrão do C++ [[08:13](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=493), [08:34](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=514)].
* Funciona como uma organização/espaço de nomes para evitar conflitos [[09:15](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=555)].


* **Função Principal (`int main()`):**
* É o ponto de entrada e o corpo principal de execução de todo programa em C++ [[10:30](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=630), [12:34](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=754)].
* Retorna um número inteiro ao sistema operacional, utilizando `return 0;` no final para indicar que a execução foi concluída sem erros [[11:32](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=692), [12:52](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=772)].


* **Comando de Saída (`std::cout`):**
* Utilizado para imprimir textos e valores na tela [[17:47](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=1067), [18:54](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=1134)].
* Substitui o tradicional `printf` da linguagem C [[18:11](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=1091)].


* **Quebra de Linha e Pausa no Sistema:**
* Para quebrar linhas, pode-se utilizar `std::endl` ou o caractere de escape `\n` [[20:49](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=1249), [22:05](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=1325)].
* O comando `system("pause");` é utilizado para pausar a execução do console antes que a janela seja fechada [[19:59](http://www.youtube.com/watch?v=JIZOkmyPbOM&t=1199)].
