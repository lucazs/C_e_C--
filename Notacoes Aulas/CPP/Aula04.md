# 📹 Curso de C++ #04 - Variáveis em C++

Nesta aula, o professor Bruno explica o conceito fundamental, a utilidade e a forma de declaração e manipulação de variáveis na memória do computador.

## 📌 Conceitos Principais e Detalhes da Aula

* **O que são Variáveis:** São posições reservadas temporariamente na memória RAM pelo sistema operacional para armazenar, modificar ou consultar dados durante a execução do programa.
* **Inicialização e Lixo de Memória:** Ao criar uma variável sem atribuir um valor inicial, a posição de memória pode conter dados imprevisíveis deixados por outros processos (chamado carinhosamente de "lixo"). Por isso, é fundamental inicializar as variáveis antes do uso.
* **Principais Tipos de Dados em C++:**
* `int`: Armazena números inteiros positivos ou negativos (ex: 0, 10, 250).
* `char`: Armazena um único caractere ocupando 1 byte de memória, representado entre aspas simples/apóstrofo (ex: `'B'`).
* `double`: Armazena números reais com casas decimais (ponto flutuante) e alta precisão (ex: `5.2`).
* `float`: Semelhante ao `double`, porém com menor precisão decimal.
* `bool`: Tipo booleano que assume apenas os valores `true` (verdadeiro / `1`) ou `false` (falso / `0`).
* `string`: Utilizado para armazenar cadeias de caracteres (textos maiores) delimitadas por aspas duplas (ex: `"Bruno"`).

* **Entrada e Saída de Dados:**
* `std::cout`: Comando de saída utilizado com o operador `<<` para exibir mensagens ou os valores das variáveis na tela.
* `std::cin`: Comando de entrada utilizado com o operador `>>` para capturar os dados digitados pelo usuário no teclado e armazená-los nas variáveis.
* **Comentários de Código:**
* Comentário de linha única: Utiliza `//`.
* Comentário de bloco/múltiplas linhas: Utiliza `/*` no início e `*/` no término.
