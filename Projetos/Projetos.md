# Projetos para Iniciantes (Apenas Texto / Console)

* *Calculadora Simples*: Menu de opções para somar, subtrair, multiplicar e dividir dois números.
* *Jogo de Adivinhação*: O computador gera um número aleatório e o usuário tenta adivinhar com dicas de "maior" ou "menor".
* *Gerador de Tabuada*: O usuário digita um número e o programa exibe a tabuada completa de 1 a 10 usando loops.
* *Conversor de Moedas*: Transforma valores entre Real, Dólar e Euro usando taxas de câmbio fixas em variáveis.
* *Verificador de Palíndromos*: Recebe uma palavra e diz se ela se lê igual de trás para frente.
